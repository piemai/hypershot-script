# HyperShot Elite v2.0 🎯

A high-performance, glassmorphic Roblox combat utility script featuring predictive aimbot, silent bullet redirection, full ESP suite, and modular UI framework integration.

---

## Features

- **Predictive Aimbot:** Linear velocity vector calculation to accurately track moving targets.
- **Silent Bullet Redirection:** Namecall/Raycast hooking to redirect projectiles towards targets inside your FOV.
- **ESP Suite:** 
  - Dynamic Team/Enemy color coding (Green / Red)
  - Box ESP & Health Bars
  - Distance & Name tags
  - Snapline Tracers
- **Custom UI Framework:** Smooth glassmorphic interface with draggable windows, customizable themes, and minimizable layouts.
